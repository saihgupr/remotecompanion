Hardware & Gesture Triggers

Buttons & Sensors

Bind multi-step action sequences to physical buttons, device sensors, and hardware state changes.

  • ✓ Power & Volume button hold & combos
  • ✓ Touch ID tap / long-press & Ringer switch
  • ✓ NFC background tags & Proximity pocket detection
  • ✓ Power connect/disconnect & Status Bar double-tap
  • ✓ Rotation, Find My Sound, Calls, Battery Level & Focus triggers
  • ✓ Two-finger edge swipes & recorded gestures at 0.5x to 3x

Integrations Hub

IoT & Desktop Automation

Seamlessly communicate with smart home ecosystems, Mac productivity tools, and IoT brokers.

  • ✓ Home Assistant: Full entity picker & live state control
  • ✓ Keyboard Maestro: Visual macro picker & params
  • ✓ Native MQTT: Publish actions & background subscription triggers
  • ✓ Siri Shortcuts: Deep native workflow integration
  • ✓ App Quick Action: App shortcuts read live from SpringBoard

Camera & Stealth Actions

Capture & Lockscreen

Automated photo/video recording and lockscreen camera bridging for instant capture.

  • ✓ Lock Screen Camera Launch Trigger bridging
  • ✓ Video recording automation with custom modes & zoom
  • ✓ Native SneakyCam background photo/video triggers
  • ✓ Haptic feedback & HUD toast overlays

Scripting & Conditional Logic

Lua, Time & Safe Mode

Build smart branching rules with time-of-day, proximity, Bluetooth connection, and Lua engines.

  • ✓ Time of Day: If Time Between AM/PM conditional blocks
  • ✓ Location Services: Native GPS toggle & status queries
  • ✓ Safe Mode: One-tap diagnostic restart via CLI & UI
  • ✓ Lua Engine: Full Objective-C runtime bridge (`objc_call`)
  • ✓ Variables: Set Variable, {name} substitution & Variable conditions
  • ✓ Reusable: Copy and paste actions across triggers
Desktop Web Interface

Visual Workflow Hub & Live Diagnostics

Manage triggers, build drag-and-drop action sequences, monitor system health, and copy API endpoints right from your desktop browser at http://[DEVICE_IP]:8080. Follows system light mode, with an optional token gating privileged API commands.

Release Notes

What's New in v4.4

November 2026
New

New Triggers: Rotated to Landscape / Portrait, Find My Sound, Incoming Call / Call Started / Call Ended, Battery Level (1-100%), and Focus on / off for a chosen Focus or any Focus.

New

Gesture Recorder: Settings → Gestures records taps, swipes and scrolls, plays back at 0.5x to 3x, with trim, re-record, replace, rename, export and import.

New

Faster Building: Compact tile layout with trigger icons, and copy and paste for actions.

New

Variables: Set Variable action, {name} substitution in action text, a Variable condition, and a saved list in Settings → Advanced Settings → Variables.

New

App Quick Action: Pick an app, then one of its registered shortcuts, read live from SpringBoard so the Home Screen menu never has to be opened first.

New

Excluded Apps: Settings → Advanced Settings → Options lists every trigger that has actions, grouped like the Triggers page, and sets the apps where each one stays quiet.

UI Refresh

Web UI & Edge Gestures: Web UI follows system light mode, edge swipes accept a second finger, and /api/command supports an optional token gating privileged commands.

Security

Fixes: Hardened ssh-run quoting and rc-root caller check, plus Bottom Swipe Up zone, SSH banner matching, and Touch ID trigger fixes.

2

Search for RemoteCompanion and install the latest release.

3
